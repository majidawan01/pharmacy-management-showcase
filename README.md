# Pharmacy Management System (Showcase)

A Windows desktop application for running a pharmacy's daily operations offline, built with C# WPF and a local SQLite database.

This was a client project, so the source code is private. This repository describes the project and its features.

## Key Features

- **Login:** username and password login, with password change from Settings
- **Dashboard:** summary of sales and business activity with charts
- **Medicines and stock:** add, edit and manage medicine records
- **Sales:** create sales and print invoices
- **Purchases:** record purchases from suppliers and print purchase vouchers
- **Returns:** record returned items
- **Accounts and debts:** track customer and supplier accounts and outstanding debts
- **Employees, salaries and expenses:** maintain staff records, pay salaries and log expenses
- **Reports:** sales, purchase and financial reports with printing
- **Barcodes:** generate and print barcode labels
- **Activity logs:** record of actions taken in the app
- **Multiple languages:** English, Pashto, Dari and Urdu
- **Offline:** runs fully on one computer with a local database, with no internet or server needed
